# Leonardo legacy operations

The files in this directory are historical Leonardo launch, smoke, debug, and
cluster-utility scripts. They are retained for provenance only and are not part
of the active experiment workflow.

The current official controlled-fusion campaign uses the Snellius workflow in
`snellius/` together with the controlled B/C/D/E/H training and evaluation
wrappers at the repository root. Canonical experiment definitions, including
the VLM3R A baseline recipe, remain in their active locations.

Archived files preserve their former repository-relative layout below this
directory. Their embedded Leonardo paths and relative references have not been
rewritten, so they should not be submitted from the archive.
